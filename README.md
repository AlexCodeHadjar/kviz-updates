# QUIZON — обновления

Здесь лежат только готовые файлы программы QUIZON: установщик и пакеты обновлений. Исходного кода здесь нет.

## Как обновиться

**Обычно ничего скачивать не нужно.** Когда выходит новая версия, на пульте ведущего в блоке «Программа» появляется кнопка
«Обновить до …». Нажмите её — программа сама скачает обновление, проверит подпись и перезапустится.
Если в это время идёт игра, установка подождёт её окончания.

Если интернета на ноутбуке нет или кнопка не сработала:

1. Откройте раздел [Releases](../../releases) и скачайте файл `QUIZON-<версия>.kvizupdate` на любом компьютере.
2. Перенесите его на ноутбук ведущего.
3. На пульте нажмите «Обновить из файла…» и выберите этот файл.

## Новая установка

Скачайте `QUIZON-Setup-<версия>.exe` из [Releases](../../releases) и запустите его.
После установки программа попросит ключ подписки — его выдаёт продавец.

## Безопасность

Каждый пакет подписан ключом продавца. Программа не установит файл, если он изменён или подписан чужим ключом,
поэтому скачивайте обновления только отсюда.

Вопросы и ключи подписки — у продавца: Telegram [t.me/miseria_void](https://t.me/miseria_void).
